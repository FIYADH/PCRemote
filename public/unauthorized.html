Device not authorized

PC Remote

This device doesn't carry the access certificate, so the PC refused the connection. Access is locked to one enrolled laptop.

  1. On the PC, open the folder data\enroll inside the PC Remote folder.
  2. Copy the whole folder to this device (USB drive or Tailscale).
  3. Run install-on-laptop.bat and click Yes if Windows asks.
  4. Close every browser window, reopen it, and come back to this address.

جهاز غير مصرّح

هذا الجهاز لا يحمل شهادة الدخول، لذلك رفض البي سي الاتصال. الدخول مقفل على لابتوب واحد مسجّل فقط.

  1. على البي سي، افتح المجلد data\enroll داخل مجلد PC Remote.
  2. انسخ المجلد كاملاً إلى هذا الجهاز (فلاش أو Tailscale).
  3. شغّل install-on-laptop.bat ووافق إذا طلب ويندوز.
  4. أغلق كل نوافذ المتصفح، ثم افتحه وارجع لنفس العنوان.
